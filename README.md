# ESS 배터리 수명 예측

초기 100 사이클 데이터만으로 리튬이온(LFP/흑연) 셀의 **EOL 수명(cycle_life, SOH 80% 도달 사이클)** 을 예측하는 회귀 모델. ESS 에서 배터리 교체 비용이 CAPEX 의 30∼40% 를 차지하므로, 열화가 시작되기 전에 셀별 교체 시점을 예측하는 것이 목적이다.

## 프로젝트 개요
- 데이터셋 : MIT-Stanford Battery Dataset (Severson et al., Nature Energy 2019)
- 학습 : Batch 1 (2017-05-12) → Train / Valid(Hold-out)  ·  평가 : Batch 2 (2018-02-20), 추가 평가 Batch 3 (2018-04-12)
- 태스크 : **Regression**, 타깃 `log10(cycle_life)`, 지표 MAPE (예측 후 `10^` 역변환, 사이클 단위로 계산)
- 정제 후 115셀 : Batch1 36 / Batch2 39 / Batch3 40

## 무엇을, 왜, 어떻게 바꿨나
| 단계 | 한 일 | 이유(근거) | 결과 |
|---|---|---|---|
| Day 1 EDA | 수명 분포, 열화 곡선, ΔQ(V), 충전 조건, 피처 상관 분석 | 모델 전략의 근거를 데이터에서 찾기 위해 | ΔQ 분산이 수명과 가장 강하게 연결(r≈−0.85), 배치 간 분포가 다름 |
| Day 1 전략 | ΔQ 중심 피처 + 규제 선형 모델 + 배치 이동 점검, 검증은 랜덤 CV 계획 | 소표본·공선성·배치 이동 | Day 2 에서 검증 설계는 수정 |
| Day 2 정제 | 5단계 정제, 이어측정 병합은 검증 후 적용 | 라벨 결측·센서 이상·논문 병합 규칙의 불일치 | 139셀 → 115셀 |
| Day 2 검증 | 랜덤 CV → **정책 단위 CV** | 같은 정책의 형제 셀이 학습에 들어가는 누수 | 27개 조합 모두 정책 CV 가 더 나쁨 |
| Day 2 모델 | 27개 조합 비교, 정책 CV 최소 선택 | 소표본에서 안정적인 모델 | D6 + ElasticNet |
| 결과 후 수정 | 외삽 CV 로 재선택 시도, 정제 오류 2건 수정 | Test 격차 분석, 다른 구현과의 비교 | Test B2 38.5 → 26.9 |
| **추가 분석** | SHAP 으로 Batch 2 편향을 피처별로 분해 | 초기 용량 피처가 원인이라는 가설을 확인하기 위해 (모델은 변경 없음) | 편향의 약 1/5 만 초기 용량 피처, 나머지는 ΔQ–수명 관계의 배치 간 차이 |

## 추가 분석 : SHAP 으로 Batch 2 오차의 출처 진단
Test(Batch 2) MAPE 26.9%, 39셀 중 38셀이 실제보다 길게 예측됐다. 이런 격차를 만나면 모델이나 피처를 바꿔 가며 점수를 올리고 싶어지지만, Test 를 반복해서 보며 고치면 평가가 더 이상 독립적이지 않다. 그래서 **모델은 고정한 채 SHAP 으로 예측을 피처별 기여로 분해해, "왜 틀렸나"에 대한 우리 가설을 검증**했다(`notebooks/04_interpretation.ipynb`, 모델 선택에는 미사용).

| 우리 가설 | SHAP 으로 확인한 결과 |
|---|---|
| 배치마다 값 범위가 다른 초기 용량 피처(`QD_2`, `QD_max_minus_2`)가 과대예측의 주원인이다 | **일부만 맞았다.** 이 피처들의 기여를 0 으로 두어도 평균 편향이 +25% → +20% 로만 줄었다. 편향의 약 1/5 만 여기서 왔다 |
| (확인 결과 새로 드러남) | 나머지는 **ΔQ 와 수명의 관계가 Batch 2 에서 낮은 쪽으로 어긋난 데서** 왔다. 실제 수명은 학습 평균보다 로그 기준 0.16 짧아졌는데, ΔQ 피처가 만든 예측 이동은 0.084 뿐이었다. 같은 모델이 Batch 3 에서는 예측 이동(+0.111)이 실제 이동(+0.108)과 거의 일치 |
| 셀 단위로도 같은가 | 가장 크게 틀린 `b2c44`(실제 841 → 예측 1,600)는 ΔQ 값이 학습 최저값보다도 낮아, 모델이 학습 범위 밖의 값을 선형으로 연장해 수명을 크게 끌어올렸다. 반대로 `b2c11`(449 → 464)은 피처가 모두 학습 범위 안이라 정확히 맞혔다 |

**얻은 것.** 단순히 "Batch 2 는 분포가 달라서 틀렸다"에서 나아가, 오차의 출처를 *피처 단위로 정량화*했고 우리의 첫 가설이 부분적으로만 맞았다는 것까지 확인했다. 이 결과는 "피처를 더하거나 빼기"보다 **새 배치에서 소수 셀로 ΔQ–수명 관계를 재보정**하는 쪽이 더 직접적인 처방일 수 있음을 시사한다(Test 를 본 뒤 나온 가설이라 검증하지 않았다). SHAP 은 모델이 무엇에 반응했는지를 보여 줄 뿐 물리적 원인을 증명하지는 않는다.

## 1. Day 1 : EDA 로 세운 모델링 전략
EDA 에서 확인한 사실과 그에 따른 전략이다. 수치는 Day 1 정제본(Batch 1 41셀) 기준이며, Day 2 에서 다시 계산한 값은 괄호로 병기했다.

| EDA 에서 확인한 사실 | 모델링 전략 |
|---|---|
| **배치 간 분포가 다르다.** 수명 392∼1,935, Batch 2 의 28/39 셀이 Train 최솟값(534)보다 짧고 Batch 3 는 Train 최댓값을 넘는 셀이 많음 | 학습이 못 본 범위를 맞혀야 하므로 모델별 외삽 성향을 비교하고, 오류를 수명 범위별로 분석 |
| **초기 100 사이클의 용량 변화만으로는 장·단수명이 구분되지 않는다.** 변화량 중앙값 약 1.7 mAh(정격의 0.15%) | 용량 변화량이 아니라 방전 곡선의 *형태* 를 피처로 사용 |
| **log10 Var(ΔQ) ↔ log10 수명 r = −0.85**, 세 배치에서 같은 방향 (Day 2 재계산 : B1 −0.84 / B2 −0.92 / B3 −0.81) | `dq_log_var` 를 핵심 피처로 두고 ΔQ 통계 피처 중심으로 구성 |
| ΔQ 통계 피처끼리 공선성이 큼 | Ridge · ElasticNet · PLS 같은 규제·차원축소 모델 후보에 포함 |
| 충전 속도(C-rate)는 단독 설명변수가 못 된다. 같은 정책 안에서도 셀 간 편차가 있고, `-newstructure` 셀은 같은 정책에서 1.6∼2.2배 오래 감 | 충전 조건은 보조 피처로만 검토, `-newstructure` 플래그는 Train 에 없으므로 제외 |
| 운전·상태 피처(충전시간, 저항, 온도)는 배치마다 상관 부호가 뒤집힘 (`notebooks/02`) | 일반화 위험이 있어 보조 후보로만 두고 피처셋 비교 |
| 학습 셀이 소수 | 단순·규제 모델 위주, 피처 수를 1∼7개로 제한 |
| 열화는 수명의 약 77% 지점에서 Knee 가 오고 이후 약 10배 빨라짐 | Knee 는 100 사이클 시점에 알 수 없으므로 피처에서 제외(누수 방지) |

검증 계획은 *수명 층화 Hold-out + 셀 단위 랜덤 5-Fold* 였다. 이 부분은 Day 2 에서 바꿨다(3절).

## 2. Day 2 : 데이터 정제
정제는 원본 `.mat` 에서 직접 수행한다(`src/preprocess.py`). 단계마다 이유와 남는 셀 수는 다음과 같다.

| 단계 | 처리 | 이유 | 남은 셀 (B1/B2/B3) |
|---|---|---|---|
| 0 | `.mat` 추출 | | 139 (46/47/46) |
| 1 | `cycle_life` 결측 제거 | 타깃이 없으면 학습·평가 불가 (Batch 2 의 8셀, Batch 3 의 2셀) | 129 (46/39/44) |
| 2 | 이어측정 병합은 **검증 후에만** 적용 | 논문은 Batch 1 미완료 셀을 이어 측정 셀과 합쳐 수명을 보정하나, 우리 Batch 2 파일은 사이클 수가 논문 값과 달라(예: b2c7 806 vs 662) 같은 셀로 볼 근거가 없음 → 5쌍 모두 병합하지 않음 | 129 |
| 3 | 물리 범위 밖 값을 NaN 처리 후 선형 보간(연속 5개까지) | 센서 이상값 | 129 |
| 4 | 논문 공개 제거 목록 9셀 제거 | Batch 1 80% 미도달 5, Batch 3 채널 노이즈 4 | 120 (41/39/40) |
| 4b | **EOL 미도달 라벨 제거** (마지막 5개 용량 중앙값 > 0.90Ah) | 아래 트러블슈팅 참고 | 115 (36/39/40) |
| 5 | 초기 윈도우 무결성 확인 | cycle 100 까지의 데이터와 ΔQ 곡선이 유효해야 피처 계산 가능 | 115 |

- **누수 방지** : 모든 피처는 cycle ≤ 100 데이터만 사용한다. 결측 대체·표준화는 학습 fold 안에서만 학습한다.
- **ΔQ(V)** = cycle 100 − cycle 10 의 방전 곡선(Qdlin) 차이. 요약 통계(분산, 최솟값, 왜도, 첨도)를 피처로 쓴다.

## 3. Day 2 : 피처와 검증 설계
### 피처 선별 (`notebooks/02_feature_engineering.ipynb`)
| 구분 | 피처 | 판단 |
|---|---|---|
| 핵심 | `dq_log_var` | 상관 최상위, 세 배치 일관, 물리적 해석 가능 |
| ΔQ 형태 | `dq_log_abs_min`, `dq_skew`, `dq_kurt` | 분산이 못 잡는 곡선 형태 보완 |
| 초기 용량 | `QD_2`, `QD_max_minus_2` | 논문 Discharge 모델 피처. 단, 배치 간 값 범위 이동이 큼 (오류 분석 참고) |
| 운전·상태 | `chargetime_avg_2_6`, `Tavg_mean_2_100`, `IR_min_2_100` | 후보. 배치마다 부호가 뒤집혀 일반화 위험 |
| 제외 | `QD_slope_*`, `QD_intercept_2_100`, `t80_min`, `C_avg`, newstructure 플래그, Knee 계열 | 기울기는 Batch 2 에서 부호가 뒤집히거나 상관이 약함, 절편은 `QD_2` 와 상관 1.0, 나머지는 중복·Train 에 없는 값·100 사이클에 알 수 없는 값 |

### 검증 설계 : 정책(충전 프로토콜) 단위 분리
- Batch 1 → **Train 29셀 / Valid(Hold-out) 7셀**. 같은 정책의 셀이 Train 과 Valid 에 함께 들어가지 않도록 정책 단위로 분리한다(Valid 4개 정책). Train CV 도 정책 단위 Repeated 5-Fold × 10.
- Batch 2·3 은 모델 선택에 쓰지 않고, 선택이 끝난 뒤 평가에만 사용한다.
- **Day 1 계획에서 바꾼 이유** : Batch 1 은 정책당 셀이 1∼3개인 구조라 셀 단위 랜덤 분할은 같은 정책의 형제 셀을 학습에서 보여 준다. 운전 조건 피처는 같은 정책이면 값이 거의 같아, 모델이 새 셀이 아니라 *이미 본 정책* 을 맞히게 된다. 같은 모델·피처로 비교하자 **27개 조합 모두 정책 단위 CV 가 랜덤 CV 보다 나빴다(평균 +0.9%p)** (`results/figures/cv_random_vs_group.png`). 랜덤 분할이 낙관적이라고 판단해 랜덤 CV 에서 정책 단위 CV 로 옮겼다.

## 4. Day 2 : 모델 선택
- **후보** : Linear, Ridge, ElasticNet, PLS(2), GPR, GBM(depth 2) × 피처셋 5개 = 27개 조합. 논문 Variance 선형 모델을 베이스라인으로 둔다.
- **1차 선택 규칙(사전 확정)** : Train 정책 단위 CV MAPE 최소 → **`ΔQ 4개 + QD_2 + QD_max_minus_2`(D6) + ElasticNet**(CV 5.5%). 상위 3개(ElasticNet 5.5 / Ridge 5.6 / Linear 5.7)는 차이가 CV 표준편차(1.4)보다 작아 사실상 동급이며, 소표본·공선성 환경에서 규제된 선형 모델이 안정적이었다. 같은 피처셋에서 GPR(6.5)·GBM(11.3)은 더 나빴다.
- **개선 단계** : Test 에서 큰 격차를 본 뒤, Batch 1 안에서만 **외삽 CV**(수명이 가장 짧은 정책 20·25·30% 를 검증으로)를 만들고 `(정책 CV + 외삽 CV)/2` 최소로 재선택했다. 선택 규칙은 외삽 CV 값을 보기 전에 확정했다.

## 5. 성능 결과
지표 : MAPE (%). Gap 은 Train-Valid = Valid − Train, Valid-Test = Test − Valid, Target-Test = Test − 9.1, Batch2-Batch3 = Batch3 − Batch2.

| 구분 | MAPE (%) | 비고 |
|---|---|---|
| Train (Batch 1 CV) | 5.5 | 정책 단위 Repeated 5-Fold × 10, SD 1.4 |
| Valid (Batch 1 Hold-out) | 7.5 | 7셀(4개 정책). 30개 시드 평균 6.2 ± 1.5 (3.1 ∼ 9.1) |
| Test (Batch 2) | **26.9** | 39셀, Batch 1 전체(36셀)로 재학습. Train(29셀)만으로 학습 시 26.8 |
| Gap (Train-Valid) | +2.0 | (+) : 과적합 의심 → 과적합 징후 작음 |
| Gap (Valid-Test) | +19.4 | (+) : 배치간 일반화 저하 의심 → **Batch 2 에서 크게 저하** |
| Gap (Target-Test) | +17.8 | Target : 원논문 9.1% (Batch 2 기준) |
| Test (Batch 3) | **9.8** | 40셀 (전부 `-newstructure`) |
| Gap (Batch2-Batch3) | −17.1 | Batch 3 가 Batch 2 보다 17.1%p 낮음 |
| Gap (Target-Test) [Batch 3] | +0.7 | Batch 3 기준. 논문은 다른 데이터 구성·분할이라 참고값 |

- **개선 단계(Ridge, 외삽 반영)** : Train 5.6 / Valid 7.5 / Test B2 27.5 / Test B3 9.8 → **개선 없음.** 차이(0.6%p)가 CV 표준편차(1.4)보다 작아 노이즈 수준이고, 외삽 CV 는 Batch 1 안의 상황이라 Batch 2 의 오차 원인(배치 간 차이)을 다루지 못했다. 사전에 정한 규칙의 1차 모델(ElasticNet)을 최종으로 유지한다.
- **참고(모델 선택에는 미사용)** : 논문 Variance 베이스라인(`dq_log_var` 선형)은 CV 8.7 / Valid 9.7 / Test **B2 28.6 / B3 11.7**. 최종 모델과의 Test 차이(약 2%p)는 표본 규모와 배치 간 변동에 비해 작아, 최종 모델이 의미 있게 낫다고 말하기는 어렵다.

전체 비교표 : `results/cv_comparison.csv`, `results/baseline_vs_final.csv`, 단계별 결과 : `results/stage1/`, `results/stage2/`

## 7. 오류 분석
- **Batch 2 : 거의 전 셀을 실제보다 길게 예측.** 39셀 중 38셀(97%)이 과대예측, 평균 편향 +26%. 실제 수명 구간별 MAPE 는 450 미만(15셀) 25.2%, 450∼550(15셀) 21.6%, 550∼800(2셀) 65.9%, 800 초과(7셀) 30.9%.
- **학습 수명 범위와의 관계.** Batch 2 의 30셀은 Train 최솟값 아래이고 MAPE 23.4%. 범위 안 7셀은 오히려 47.9%, 범위 위 2셀은 6.6%. 범위 밖이라는 이유만으로는 오차가 설명되지 않는다.
- **`-newstructure` 셀이 가장 크게 틀림.** Batch 2 의 9셀 MAPE 38.7%, 나머지 30셀 23.4%. 가장 큰 오차 셀은 모두 이 그룹이다 : b2c44 (실제 841 → 예측 1,600, 90%), b2c9 (791 → 1,358, 72%), b2c7 (777 → 1,245, 60%).
- **Batch 3 는 같은 구조(전 셀 `-newstructure`)인데도 MAPE 9.8%, 평균 편향 +1.5%.** 학습 최댓값을 넘는 13셀 10.5%, 범위 안 27셀 9.5%. 따라서 "newstructure 라서 틀린다"로 단정할 수 없고, Batch 2 의 오차는 배치 특성(제조 로트 등)과 겹친 것으로 보이나 원인은 확정하지 못했다 *(가설)*.
- **초기 용량 계열 피처의 배치 의존성.** `QD_2` 는 Batch 2 셀 22/39, `QD_max_minus_2` 는 24/39 가 Batch 1 값 범위 밖이고 배치별 상관 부호도 뒤집힌다. 최종 모델이 이 피처를 포함하므로 Batch 2 의 편향과 관련이 있을 것이라고 가설을 세웠다.
- **SHAP 진단 결과 (`notebooks/04_interpretation.ipynb`, 모델 변경 없는 사후 분석).** 가설은 **일부만 맞았다.**
  - Batch 2 에서 실제 수명은 학습 평균보다 로그 기준 약 0.16 짧아졌는데 모델 예측은 약 0.065 만 내려갔다. ΔQ 피처가 −0.084 만큼 방향은 맞게 움직였으나 부족했고, 초기 용량 피처는 합쳐서 +0.02 로 오히려 끌어올렸다.
  - 초기 용량 기여를 0 으로 두면 평균 편향이 약 +25% 에서 +20% 로만 줄었다. **편향의 약 1/5 만 초기 용량 피처에서 왔고, 나머지는 ΔQ 와 수명의 관계가 Batch 2 에서 낮은 쪽으로 어긋난 데서 온다.** 같은 모델이 Batch 3 에서는 예측 이동(+0.111)이 실제 이동(+0.108)과 거의 일치한다.
  - 초기 용량 피처는 Batch 2 에서 영향이 2∼3배로 커지고 서로 반대 방향으로 작용해, 평균은 상쇄되더라도 셀별 예측을 흔드는 요인이다.
  - 가장 크게 틀린 셀 `b2c44`(실제 841 → 예측 1,600)는 ΔQ 피처가 Batch 1 최저값보다도 낮아, 학습 범위 밖의 값을 선형으로 연장한 결과로 읽힌다(force plot, `results/figures/shap_force_b2_worst.png`). 점 분포(beeswarm)는 `shap_beeswarm_b1.png`, `shap_beeswarm_b2.png`.
  - SHAP 은 모델이 무엇에 반응했는지를 보여 줄 뿐 물리적 원인을 증명하지는 않으며, 피처 간 상관이 높아 기여가 나뉘어 나올 수 있다.
- **개선 방향(미시도)** : SHAP 결과상 편향의 주원인이 ΔQ–수명 관계의 배치 간 이동이므로, 새 배치 도입 시 소수 셀의 실측 수명으로 재보정하는 방법이 피처 변경보다 효과적일 가능성이 크다. 그 밖에 초기 용량을 셀 자체 기준으로 정규화, 예측 구간(GPR 등) 제공. Test 를 본 뒤 나온 제안이라 검증하지 않았다.
- **한계** : 학습 36셀·Valid 7셀의 소표본이라 CV 반복의 SD 는 독립 신뢰구간이 아니다. 여러 후보 중 최소 CV 를 골랐으므로 CV 에는 선택 낙관성이 있다. Day 1 에서 Batch 2·3 EDA 를 이미 확인했으므로 완전한 블라인드 검증은 아니다.

## 8. ESS 도메인 해석
- **활용 가능한 의사결정** : 초기 100 사이클만으로 셀의 상대적 수명(단수명 셀 선별)을 가늠해 교체·예비품 계획의 우선순위를 정하는 데 쓸 수 있다 (Batch 1 내 새 충전 정책 검증 MAPE 약 6∼8%, Batch 3 MAPE 9.8%).
- **한계** : Batch 2 에서는 MAPE 26.9% 이고 97% 의 셀을 실제보다 길게 예측했다. 열화가 빠른 셀을 정상으로 오판해 교체가 늦어질 수 있는 방향이라 ESS 안전 관점에서 불리하며, 이 모델의 예측값만으로 교체 시점을 확정할 수 없다.
- **실 배포를 위해 필요한 것** : 로트별 재보정(소수 셀 실측으로 보정), 예측 구간 기반 보수적 의사결정, 배치 간 일관된 피처(방전 곡선 형태) 중심 설계, 실험실 고속 충전 셀 결과를 ESS 운전(SOC·온도·저율·달력 열화·팩 내 편차)으로 확장하기 위한 현장 데이터 검증.
